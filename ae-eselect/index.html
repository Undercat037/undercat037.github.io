AE-ESELECT

A modular eselect for aura-emerge: profiles, repositories and their keys, world, caches, the pacman db lock and Java environments.

Get started View on GitHub

Features

Like in Gentoo, eselect is a separate package next to emerge. One binary, eight modules: everything auxiliary that the package manager itself should not have to do — profiles, repositories, world, caches, the db lock and Java environments. Як і в Gentoo, eselect — окремий пакунок поруч із emerge. Один бінарник, вісім модулів: усе допоміжне, чим менеджер пакунків сам не повинен займатися — профілі, репозиторії, world, кеші, блокування бази й Java-середовища. Как и в Gentoo, eselect — отдельный пакет рядом с emerge. Один бинарник, восемь модулей: всё вспомогательное, чем менеджер пакетов сам заниматься не должен — профили, репозитории, world, кеши, блокировка базы и Java-окружения.

Quick start

Not installed yet? See the installation guide.

  1. See a module's actions — every module works the same way: Дії модуля — усі модулі працюють однаково: Действия модуля — все модули работают одинаково: 
    eselect profile
  2. Switch the profile by number or by path: Змінити профіль за номером або шляхом: Сменить профиль по номеру или по пути: 
    sudo eselect profile set 3
  3. Add a repository, with its signing key: Додати репозиторій, разом із ключем підпису: Добавить репозиторий, вместе с ключом подписи: 
    eselect repository add my-repo <uri> --sig L
  4. Preview a full cache cleanup before running it: Спочатку переглянути повне чищення кешів: Сначала посмотреть полное очищение кешей: 
    eselect cache clean --all -p
