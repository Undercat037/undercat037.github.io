Documentation

Module reference: profile, repository, reflector, world/news/cache/db/java and the files ae-eselect manages.

Installation

Through aura-emerge (recommended):

git clone https://github.com/Undercat037/ae-eselect
cd ae-eselect
emerge --usepkgbuild ./ --ask

Through makepkg or make:

makepkg -si
# or
make install

Dependencies: gnupg (key import for repositories), pacman (libalpm), curl (for reflector) and aura-emerge itself (eselect edits /etc/portage/, which is pointless without AE).

Через aura-emerge (рекомендовано):

Usage

The output follows Gentoo eselect: bold green list headings, a numbered [N] column, * marks the active entry, errors look like !!! Error: …. Global options: --brief (no headings, no * marker) and --colour=yes|no|auto.

$ eselect                          # global options and the module list
$ eselect profile                 # the actions of one module
$ eselect profile help           # the same, with descriptions
$ eselect <module> <action> --help   # man eselect-<module>-<action>
$ eselect profile list            # numbered list, the current one marked *
$ sudo eselect profile set 3      # by number, or by path

Вивід слідує Gentoo eselect: жирні зелені заголовки списків, нумерована колонка [N], * позначає активний запис, помилки виглядають як !!! Error: …. Глобальні опції: --brief (без заголовків і позначки *) та --colour=yes|no|auto.

$ eselect                          # глобальні опції та список модулів
$ eselect profile                 # дії одного модуля
$ eselect profile help           # те саме, з описами
$ eselect <module> <action> --help   # man eselect-<module>-<action>
$ eselect profile list            # нумерований список, поточний позначено *
$ sudo eselect profile set 3      # за номером або шляхом

Вывод следует Gentoo eselect: жирные зелёные заголовки списков, нумерованная колонка [N], * помечает активную запись, ошибки выглядят как !!! Error: …. Глобальные опции: --brief (без заголовков и отметки *) и --colour=yes|no|auto.

$ eselect                          # глобальные опции и список модулей
$ eselect profile                 # действия одного модуля
$ eselect profile help           # то же, с описаниями
$ eselect <module> <action> --help   # man eselect-<module>-<action>
$ eselect profile list            # нумерованный список, текущий помечен *
$ sudo eselect profile set 3      # по номеру или пути

profile

A profile is a leaf directory of the /var/db/portage/profiles tree that contains packages, package.profile, package.mask, make.defaults or parent. set takes a number from list, an absolute path or a path relative to the tree; the link is written as a relative one and replaced atomically. If make.profile is a real directory or file, set asks and moves it to make.profile.bak — it never deletes it. Like the original, set prints nothing on success.

$ eselect profile show
$ sudo eselect profile set default/linux/amd64/23.0

Профіль — кінцевий каталог дерева /var/db/portage/profiles, що містить packages, package.profile, package.mask, make.defaults або parent. set приймає номер із list, абсолютний шлях або шлях відносно дерева; посилання пишеться відносним і замінюється атомарно. Якщо make.profile — справжній каталог чи файл, set питає і переносить його у make.profile.bak — ніколи не видаляє. Як і оригінал, set нічого не друкує при успіху.

$ eselect profile show
$ sudo eselect profile set default/linux/amd64/23.0

Профиль — листовой каталог дерева /var/db/portage/profiles, содержащий packages, package.profile, package.mask, make.defaults или parent. set принимает номер из list, абсолютный путь или путь относительно дерева; ссылка пишется относительной и заменяется атомарно. Если make.profile — настоящий каталог или файл, set спрашивает и переносит его в make.profile.bak — никогда не удаляет. Как и оригинал, set при успехе ничего не печатает.

$ eselect profile show
$ sudo eselect profile set default/linux/amd64/23.0

repository

AE reads /etc/portage/repos.conf (FEATURES="repos"); eselect owns exactly one file there, /etc/portage/repos.conf/eselect.conf. enable/add write a [name] block with the keys AE understands (priority, sync-uri, include, verify-signature, location, auto-sync, sync-type); disable keeps the block as #| -commented lines so enable can restore it; remove deletes it. A name already defined in another repos.conf file produces a warning and a question; if repos.conf is still a single file, eselect offers to turn it into a directory (the old file becomes repos.conf/00-main.conf), and it warns when FEATURES="repos" is not set.

$ eselect repository list -i
$ sudo eselect repository enable chaotic-aur   # from the local db + key import
$ sudo eselect repository add myrepo 'https://example.org/$repo/os/$arch' -p 60
$ sudo eselect repository disable myrepo       # block stays, enable restores it
$ sudo eselect repository remove -f myrepo

Keys

On enable|add (the first match wins): /usr/share/pacman/keyrings/<name>.gpg (+ -trusted/-revoked, the same steps as pacman-key --populate <name>), or /var/db/portage/repos/<name>/keys/<name>.gpg from the local repository database. A template /var/db/portage/repos/<name>/<name>.conf is optional; a mirrorlist next to it is installed if the include target is missing. packages [-v] [-r] <name> reads /var/lib/pacman/sync/<name>.db directly and prints one package per line, plain text — suitable for redirection (-v adds the version, -r adds the <repo>/ prefix).

AE читає /etc/portage/repos.conf (FEATURES="repos"); eselect володіє там рівно одним файлом, /etc/portage/repos.conf/eselect.conf. enable/add пишуть блок [name] з ключами, які розуміє AE (priority, sync-uri, include, verify-signature, location, auto-sync, sync-type); disable лишає блок як рядки з коментарем #| , щоб enable міг його відновити; remove видаляє. Ім'я, вже визначене в іншому файлі repos.conf, дає попередження й питання; якщо repos.conf — ще одиночний файл, eselect запропонує перетворити його на каталог (старий файл стане repos.conf/00-main.conf), і попередить, коли FEATURES="repos" не задано.

$ eselect repository list -i
$ sudo eselect repository enable chaotic-aur   # з локальної бази + імпорт ключів
$ sudo eselect repository add myrepo 'https://example.org/$repo/os/$arch' -p 60
$ sudo eselect repository disable myrepo       # блок лишається, enable відновить
$ sudo eselect repository remove -f myrepo

Ключі

На enable|add (перший збіг): /usr/share/pacman/keyrings/<name>.gpg (+ -trusted/-revoked, кроки як у pacman-key --populate <name>) або /var/db/portage/repos/<name>/keys/<name>.gpg з локальної бази репозиторіїв. Шаблон /var/db/portage/repos/<name>/<name>.conf необов'язковий; mirrorlist поруч встановлюється, якщо цілі include ще немає. packages [-v] [-r] <name> читає /var/lib/pacman/sync/<name>.db напряму і друкує один пакунок на рядок — чистий текст для перенаправлення (-v додає версію, -r — префікс <repo>/).

AE читает /etc/portage/repos.conf (FEATURES="repos"); eselect владеет там ровно одним файлом, /etc/portage/repos.conf/eselect.conf. enable/add пишут блок [name] с ключами, которые понимает AE (priority, sync-uri, include, verify-signature, location, auto-sync, sync-type); disable оставляет блок строками с комментарием #| , чтобы enable мог его восстановить; remove удаляет. Имя, уже определённое в другом файле repos.conf, даёт предупреждение и вопрос; если repos.conf ещё одиночный файл, eselect предложит превратить его в каталог (старый файл станет repos.conf/00-main.conf), и предупредит, когда FEATURES="repos" не задано.

$ eselect repository list -i
$ sudo eselect repository enable chaotic-aur   # из локальной базы + импорт ключей
$ sudo eselect repository add myrepo 'https://example.org/$repo/os/$arch' -p 60
$ sudo eselect repository disable myrepo       # блок остаётся, enable восстановит
$ sudo eselect repository remove -f myrepo

Ключи

На enable|add (первое совпадение): /usr/share/pacman/keyrings/<name>.gpg (+ -trusted/-revoked, шаги как у pacman-key --populate <name>) или /var/db/portage/repos/<name>/keys/<name>.gpg из локальной базы репозиториев. Шаблон /var/db/portage/repos/<name>/<name>.conf необязателен; mirrorlist рядом устанавливается, если цели include ещё нет. packages [-v] [-r] <name> читает /var/lib/pacman/sync/<name>.db напрямую и печатает один пакет на строку — чистый текст для перенаправления (-v добавляет версию, -r — префикс <repo>/).

reflector

Ranks the mirrors of repository mirrorlists and rewrites them, fastest first. Ranking goes through the rank action: repository names follow it. Only the source in effect is read — with FEATURES="repos" in make.conf the repos.conf chain (include =), otherwise /etc/pacman.conf (Include =); repositories sharing one mirrorlist are ranked once. Every Server = line counts, commented-out ones included; each mirror is probed with curl (the first 512 KiB of <repo>.db), and a copy of the rewritten mirrorlist is kept as *.eselect-bak.

$ eselect reflector list            # which mirrorlist belongs to which repo
$ eselect reflector rank -p core blackarch   # ranking only, writes nothing
$ sudo eselect reflector rank core blackarch world system
$ sudo eselect reflector rank -n 5 --protocol all blackarch

Ранжує дзеркала mirrorlist-ів репозиторіїв і переписує їх, найшвидші першими. Ранжування йде через дію rank: назви репозиторіїв ідуть за нею. Читається лише те джерело, що діє: з FEATURES="repos" у make.conf — ланцюг repos.conf (include =), без нього — /etc/pacman.conf (Include =); репозиторії зі спільним mirrorlist ранжуються один раз. Рахуються всі рядки Server =, включно із закоментованими; кожне дзеркало пробується через curl (перші 512 КБ <repo>.db), копія переписаного mirrorlist лишається як *.eselect-bak.

$ eselect reflector list            # який mirrorlist до якого репо
$ eselect reflector rank -p core blackarch   # лише ранжування, без запису
$ sudo eselect reflector rank core blackarch world system
$ sudo eselect reflector rank -n 5 --protocol all blackarch

Ранжирует зеркала mirrorlist-ов репозиториев и переписывает их, самые быстрые первыми. Ранжирование идёт через действие rank: имена репозиториев идут за ним. Читается только действующий источник: с FEATURES="repos" в make.conf — цепочка repos.conf (include =), без него — /etc/pacman.conf (Include =); репозитории с общим mirrorlist ранжируются один раз. Учитываются все строки Server =, включая закомментированные; каждое зеркало пробуется через curl (первые 512 КБ <repo>.db), копия переписанного mirrorlist остаётся как *.eselect-bak.

$ eselect reflector rank -p core blackarch   # только ранжирование, без записи
$ sudo eselect reflector rank core blackarch world system
$ sudo eselect reflector rank -n 5 --protocol all blackarch

world · news · cache · db · java

  • world — show prints the world file; regen reads explicitly installed packages straight from /var/lib/pacman/local (without calling pacman) and appends the missing ones. -p only shows them (no root), -a asks before writing.
  • news — eselect news lists the Arch news feed, read N reads an item, read all marks everything as read.
  • cache — --pkgcache (/var/cache/pacman/pkg), --sources, --packages, --build (~/.cache/aura-emerge/… of every user) or --all; -p is a dry run, -y skips the confirmation. Under root, user-planted symlinks are not followed.
  • db — status shows the lock, its age and the running package managers; lock/unlock manage /var/lib/pacman/db.lck; unlock refuses while pacman, emerge, paru, yay or pamac-daemon runs (-f forces).
  • java — a built-in replacement for archlinux-java: status/get/set/unset/fix over /usr/lib/jvm; reachable as archlinux-java if you create that link yourself.
$ eselect world show
$ eselect world regen -p            # what would be added
$ sudo eselect world regen -a       # add the missing ones, with confirmation
$ eselect news read 8
$ sudo eselect cache clean --all -p # dry run
$ eselect db status
$ sudo eselect db unlock
  • world — show друкує world; regen читає явно встановлені пакунки прямо з /var/lib/pacman/local (без виклику pacman) і додає відсутні. -p лише показує (без root), -a питає перед записом.
  • news — eselect news показує стрічку новин Arch, read N читає пункт, read all позначає все прочитаним.
  • cache — --pkgcache (/var/cache/pacman/pkg), --sources, --packages, --build (~/.cache/aura-emerge/… кожного користувача) або --all; -p — сухий прогін, -y без підтвердження. Під root symlink-и, підсаджені користувачем, не проходяться.
  • db — status показує блокування, його вік і запущені пакетні менеджери; lock/unlock керують /var/lib/pacman/db.lck; unlock відмовляє, поки працюють pacman, emerge, paru, yay чи pamac-daemon (-f примусово).
  • java — вбудована заміна archlinux-java: status/get/set/unset/fix над /usr/lib/jvm; доступний як archlinux-java, якщо створити таке посилання самотужки.
$ eselect world show
$ eselect world regen -p            # що було б додано
$ sudo eselect world regen -a       # додати відсутні, з підтвердженням
$ eselect news read 8
$ sudo eselect cache clean --all -p # сухий прогін
$ eselect db status
$ sudo eselect db unlock
  • world — show печатает world; regen читает явно установленные пакеты прямо из /var/lib/pacman/local (без вызова pacman) и добавляет отсутствующие. -p только показывает (без root), -a спрашивает перед записью.
  • news — eselect news показывает ленту новостей Arch, read N читает пункт, read all помечает всё прочитанным.
  • cache — --pkgcache (/var/cache/pacman/pkg), --sources, --packages, --build (~/.cache/aura-emerge/… каждого пользователя) или --all; -p — сухой прогон, -y без подтверждения. Под root симлинки, подсаженные пользователем, не проходятся.
  • db — status показывает блокировку, её возраст и запущенные пакетные менеджеры; lock/unlock управляют /var/lib/pacman/db.lck; unlock отказывает, пока работают pacman, emerge, paru, yay или pamac-daemon (-f принудительно).
  • java — встроенная замена archlinux-java: status/get/set/unset/fix над /usr/lib/jvm; доступен как archlinux-java, если создать такую ссылку самостоятельно.
$ eselect world show
$ eselect world regen -p            # что было бы добавлено
$ sudo eselect world regen -a       # добавить отсутствующие, с подтверждением
$ eselect news read 8
$ sudo eselect cache clean --all -p # сухой прогон
$ eselect db status
$ sudo eselect db unlock
